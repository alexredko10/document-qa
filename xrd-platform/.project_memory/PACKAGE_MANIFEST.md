# Documentation Package Manifest

Package purpose: stable project memory for XRD implementation/review agents.

This package intentionally does not overwrite or replace:

`xrd-platform/.project_memory/AGENT_SPEC.md`

That existing document remains a higher-precedence scientific/architectural contract.

Included categories:

- project constitution;
- scientific guardrails;
- Git/working-tree safety;
- implementation/review agent bases;
- roadmap and mission registry;
- current project state;
- source reuse policy/matrix;
- scientific assumptions;
- validation strategy;
- accepted ADRs.

After installation, future mission prompts should reference these files instead of restating the entire project history.
